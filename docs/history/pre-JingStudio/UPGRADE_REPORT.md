这不是重新包装一个第三方Skill，也不是为你选择的路线再写一篇调研。升级了原包入口和执行层，保留原有方法资产，增加可运行的离线校验/编译/排版工具，使Codex可按新工作流处理现有Excel。

`ai-film-skills / ai-storyboard-director`提供导演决策方向；本包吸收该方向后独立实现。没有内嵌上游全部技能，没有冒称完整复现5.6.4；上游的打戏专项、设计记忆执行器和白模渲染等不在本版已实现范围。

## 具体修正

原包前置固定15秒/8格口径与后文实际时长规则存在冲突。现在统一为人审板>0且≤15秒、不凑时长、不按格均分；关键帧数按叙事决定，视频生产任务单独按目标profile规划。

把“一镜一张静态插图”改成观看任务、可见变化、摄影理由、世界状态与时序关键帧。补充平移/摇摄/变焦的可见证据、站位/视线、动作落点和道具因果；不把复杂运镜当成默认更高级。

将原通用QA里的旧项目角色排除名单移出活动规则；按本项目实际subjects/refs检查，不对别的项目注入人物。

原Node导入脚本依赖特定`@oai/artifact-tool`运行时；现在导入与核心编译只用Python标准库。旧Node脚本原样存档但不作为默认执行器，**不承诺旧CLI参数与新CLI兼容**。

原视频脚本截取长prompt的行为不再沿用。超长、缺图、缺英文、台词不是原文、时间不守恒或未批准拆镜会报错；不能通过删末尾文字、加秒数或空文件掩盖。

## 当前已实现

Director Contract JSON Schema；XLSX/CSV/JSON导入；未决draft生成；来源/时间/轴线/状态/参考/回执字段校验；≤15秒人审分组；显式连续性图；逐格生图任务清单；离线HTML人审合成与可选PNG；Seedance2.0/2.5和MiniMax H3提示词编译；缺素材draft；源/合同/素材哈希；默认不覆盖写入；Codex/ZCode独立名称安装、同名V3升级备份；自动化测试。

导演语义生成、中英翻译、真实看图和实际模型调用仍由Codex及其可用工具执行。没有伪装成“Python已经会自动导演整部片”。

## 未实现或需专项处理

没有真实图像/视频生成执行端；没有自动上传或供应商HTTP client；没有完整Blender/UE白模执行器；没有后台DAG记忆服务；没有自动美学/身份评分器。H3跨切点台词、合唱、复杂音视频编辑超出当前脚本标准结构，需要保留原文并专项编译。

profile是有来源和边界的离线快照，不是任意供应商payload。2.5容量不改变用户人审板≤15秒的锁定；仅文字提示不能保证模型理解毫米焦距或准确执行每秒关键帧。

## 样例与真实验证

读取了用户原Excel并核对39镜/360秒；镜9对应10秒和原工作表第10行。示例保留0–2秒向右跟拍后固定、左向右横穿、无绊倒碰撞和完整展架状态，读取8/10/11作为上下文。

示例输出是导演候选、prompt草稿及缺图人审页；并没有代用户批准，更没有生成真实关键帧或视频。10秒真实跑速与展厅尺度是否匹配仍需要预演/样片验证；不通过文字计划伪称已经解决。

当前重构测试详见TEST_REPORT.md，包括独立命名、两端临时安装、旧版保护及失败回滚。原3.0.0测试记录归档在docs/history；其中原Excel/PNG等记录属于前版构建，不表示本次重跑了所有人工步骤。没有在用户Windows或实际Codex/ZCode宿主安装，也没有进行Seedance/H3生成测试。

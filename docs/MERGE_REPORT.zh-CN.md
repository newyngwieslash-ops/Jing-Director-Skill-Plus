# 合并结论与能力映射 · 2026-09-28

建议一个能力入口，旧安装保留回退。新包不依赖两个旧安装。

V3已包含master-2前六步与12份传统参考正文。简单拼接会重复加载，并带回废止的固定15秒/8格、整页输入视频、强制逐步暂停。本次采用V3主线，补齐旧版缺项并明确规则优先级。

| 原能力/差异 | 统一版处理 |
|---|---|

| 四列执行表与三栏设计板 | 恢复三栏和16:9正式图片规范，格数按时间态；内置流式render范围单独说明 |

| 旧角色校验器 | 无npm依赖脚本恢复到scripts，只做宽松字段预检 |
| 旧分组/Seedance脚本 | 保留legacy但不用作现行执行器；Python已覆盖主要路径，旧编译器会截断台词 |
| ponytail | 用于本次简化实现，不成为导演技能外部依赖 |

# 视频生成提示词列规范

本文件定义分镜表中 `视频提示词` 列的固定结构。该列用于把每个分镜转化为可直接交给文生视频、图生视频或镜头级视频生成工具的提示词。

## 一、启用条件

当用户提出以下任何需求时，分镜表必须在原九列之后增加 `视频提示词` 列：

- 生成视频提示词
- 文生视频 / 图生视频
- 根据分镜生成视频
- 需要角色、美术、镜头风格长期一致
- 需要将 Excel 分镜表交给视频生成模型使用

如果用户只要求传统拍摄分镜表，可以保持九列结构；但一旦进入 AI 视频生产流程，必须启用本列，并且必须先完成“提取角色以保持全局一致性”得到 `character_bible.json`。

## 二、固定模板

每个镜头对应一个完整提示词块，必须使用以下字段顺序：

```text
【分镜 N】【X秒】
【时代】：...
【时间】：...
【场景】：...@
【人物】：角色A@（外观/身份/状态，角色A配音@：普通话或方言，画面无字幕），角色B@（外观/身份/状态，角色B配音@：普通话，画面无字幕）
【画面】：
Shot 1：...
对白：...
【镜头移动】：...
【音效/音乐】：...
【电影风格】：...
```

字段不得改名，不得省略。没有对白时写 `对白：无对白。`；没有明确人物时写 `【人物】：无主要人物。`

## 三、字段来源

| 字段 | 来源 | 写法要求 |
|------|------|---------|
| `【分镜 N】【X秒】` | 分镜表镜号和时长 | 镜号用连续编号；时长用秒数或原表时长 |
| `【时代】` | 剧本背景、场景、分镜内容 | 如 `现代都市`、`15世纪法国战场`、`架空古装` |
| `【时间】` | 场景名、画面内容、剧本时间 | 如 `深夜`、`白天`、`清晨`；不明确写 `未明确` |
| `【场景】` | 分镜表场景列 | 保持具体空间，并在末尾保留 `@` 标记 |
| `【人物】` | 分镜内容 + `character_bible.json` | 必须使用角色圣经中的稳定 `id` 和姓名；包含核心视觉锚点、身份、状态、配音语言、画面无字幕 |
| `【画面】` | 画面内容列 | 只写可见动作、物体、环境、视觉效果 |
| `Shot` | 实际剪辑镜头 | 单镜头保持一个Shot；长镜头内部用分时段beat，不增加Shot编号；只有真实剪辑才新增Shot |
| `对白` | 台词/人物列或声音列 | 保留角色名；无对白必须明确写无对白 |
| `【镜头移动】` | 景别 + 机位/运动 + 备注 | 用可执行摄影语言，不写抽象情绪 |
| `【音效/音乐】` | 声音列 | 只写可听元素：对白、环境音、音效、音乐 |
| `【电影风格】` | 导演定调 + 美术设定 | 固定系列风格，再叠加场景光线、色彩、质感 |

## 四、角色与美术一致性

生成提示词时必须读取并继承以下信息：

1. `character_bible.json`：角色 `id`、角色外观、服装、表情、动作习惯、配音语言、禁止漂移项。
2. `art_style_bible.json`：系列影调、色彩系统、光线规则、场景美术、分镜渲染规则。
3. 已确认的导演定调：本集镜头语言、节奏气质和视觉母题。

提示词只做镜头级转写，不新增剧情事实，不提前透露后续信息，不改变角色关系。如果当前镜头出现未登记人物，必须先补录 `character_bible.json`，不能在提示词里临时发明角色外观。

## 五、写作红线

- 不写心理活动：禁止 `他意识到`、`她感到`、`内心崩溃` 等不可拍内容。
- 不写泛化风格词堆砌：禁止只有 `电影感、大片感、高级感` 而没有光线、色彩、镜头、动作细节。
- 不改变角色设定：年龄、体型、服装气质、口音和核心识别点必须稳定。
- 不在画面中默认生成字幕，除非分镜明确需要字幕；默认写 `画面无字幕`。
- 不把多个镜头混成一个提示词；每个分镜单元格只对应当前镜头。

## 六、短镜头示例

```text
【分镜 1】【3秒】
【时代】：现代都市
【时间】：深夜
【场景】：老街酒吧外@
【人物】：无主要人物。
【画面】：
Shot 1：老街夜景，小酒吧“回声”门头亮着疲惫暖黄灯，街上人不多，空气里有城市夜晚的潮湿感。
对白：无对白。
【镜头移动】：固定全景，轻微环境观察感。
【音效/音乐】：城市远声，酒吧里轻音乐漏出。
【电影风格】：光影：高对比电影光，暖黄酒吧光与深青夜色交错；配色：深冷青、暗金、低饱和现实质感；质感：正式电影分镜，写实、压抑、带黑色喜剧刺感。
```

# 导演镜头语言引擎：从“画出来”到“让观众看懂变化”

本文件为本包独立工作方法。架构参考来源见 `docs/SOURCES.md`。执行优先级：用户事实和已批准拍法 > 当前SKILL > 本文件；不是导入上游所有输出规定。

## 观看任务先于摄影术语

读完镜头组，用一句话写清“观众此刻必须建立的关系”。例如父子镜，不先写“电影感、85mm、浅景深”，而是决定：让父亲占据近景、儿子留在后方，距离本身承担疏离；儿子说完后父亲才停步回望。若这正是既定拍法，不另插儿子特写。

把叙事目的分成信息建立、信息隐藏、关系变更、因果铺垫、动作可读、主观体验或节奏停留。它们只是问题类别，不自动映射到某个镜头。对白段可以靠同框调度而不是正反打；危险段可以固定机位而不是手持摇晃。

每镜写四项：`viewing_task`、`visible_change`、`why_this_camera`、`hidden_viewpoint_check`。简短理由足够，避免要求展示推理过程。

## 以镜头组决定覆盖

先识别镜头组的关系：同一物件的建立/使用、视线与被看对象、动作与后果、说话与反应、空间两端的人物、信息给予与隐瞒。已有分镜表默认不新增coverage；不足时提交“候选补镜”，列明新增秒数和被影响镜头，等批准后改源版本。

给每个真正不同的拍法一个观看任务，而不是给相同构图罗列不同焦段。比较时问：谁主导画面？观众何时看到关键物？人物是否看到它？切镜的理由是什么？信息是否被多交代一次？不要按全景→中景→特写的固定阶梯套整场。

## Blocking不是“写一个人物在场”

确定角色从哪里进入、沿什么通道、身体朝向、看向谁或何物、持物手、站位的遮挡、停在哪里。每个角色只写本镜必要的变化。背景人物没有新剧情时，保持原有轻微活动，不增加抢眼手势或新对白。

人物在画面移动与摄影机移动分开。主体可以走向右边而摄影机固定；摄影机横移时主体可能保持在画面同一位置。给出近景地标与远景地标的相对变化，避免把两种运动写成同一句“向右运动”。

## 景别、光学与构图选择

景别由必须辨认的信息尺寸决定。要看清气球细线缠腕，先判断中远景里能否分辨，必要时通过光线对比、简洁背景、近一点的构图实现；不能在镜9未获许可就插手腕特写。超出静帧可辨能力时报告风险。

焦段不是镜头感装饰。若没有测量或锁定值，可写“保留人物与底座前后关系的中远景，避免背景压缩到与人物贴在一起”，数值留空。焦段、FOV、传感器尺寸没有一致假设时不能同时编假数。

前景遮挡只能来自已有物件；不能加柱子/树叶/烟尘。浅景深若会抹去必须建立的危险底座，不应使用。实景灯光随世界位置延续，不为让反打更漂亮凭空增加灯。

## 让运镜可观察

| 拍法 | 需要写清的证据 | 常见误写 |
|---|---|---|
| 固定镜头 | 地标位置不变，人物或物件在其中变化 | 为“有电影感”强加慢推 |
| Pan/Tilt | 摄影机中心不移动，朝向水平/垂直改变 | 把平移轨道写成摇摄 |
| Truck/Pedestal | 中心位置横向/垂直变化，前后景有视差 | 只有画面平滑裁切，没有空间变化 |
| Dolly in/out | 与主体距离变化及透视变化 | 数字放大冒充推进 |
| Zoom | 视角变化，中心位置不变；主体/背景尺度变化 | 同时要求视差不变和强烈近大远小 |
| Orbit | 围绕明确对象走弧线，并交代朝向和遮挡变化 | 角色自转，摄影机原地不动 |
| Rack focus | 机位未变，清晰平面从A转到B，触发明确 | 全画面随机虚实波动 |

复合镜头只有在完成多段观看任务时才用。必须给起点、触发、路径/朝向分段、跟随对象、速度/停顿和落点；“推拉摇移跟升降环绕一镜到底”不是方案。

## 节拍与落点

时间从动作、台词、观察和反应的实际需要得出，不等分。小动作没有叙事功能就删，不用摸脸、眨眼、转身填满15秒。事件依赖必须有先后：接触前不能受力，受力前不能碎裂，台词未结束不能提前响应。

一个源镜内多阶段动作通常仍是一个镜头；切镜是摄影结构变化，不是节拍编号变化。剪辑点要可接：人物正朝同方向运动，目光落向同对象，动作完成在合理阶段，声音可以延续但不得提前说出下一句台词。

## 用本项目镜9检验

锁定事实：10秒；低机位中远景；左向右；**前2秒向右跟拍后停住**；后景两组仍在原区域；绣面和展架完整；未绊倒未接触。增强点是“停止跟拍后，底座成为稳定危险参照”；不是新增撞击或用慢动作塞满10秒。

需要真实试拍/预演的问题：按真实跑速，10秒横穿是否和现有展厅宽度匹配？静帧不能证明。冲突出现时保留原合同、报告空间/时长矛盾并提交批准方案；不要偷偷让男孩原地慢跑。

# F1—F19 故障分类与低损耗修复

与现有错误码并存：现有合同/来源/资产/覆盖错误仍阻断，不用F码替换。F码只描述观察到的视频/图像症状，不自动证明根因。同一镜可多码，但每次实验只改一个可归因变量，并保留已有好素材。

| 码/症状 | 首先检查的根因假设（不是断言） | 首个低损耗单变量实验 |
|---|---|---|
| F1 身份漂移 | 参考冲突、面部遮挡、身份约束不足 | 保持其余输入仅更换冲突的身份参考；先核对角色ID |
| F2 幻灯片/不动 | 动作描述不明确或输入模式不合 | 只把已有动作写成可观察运动句，不新增动作 |
| F3 形体变形/融化 | 高运动复杂度或边界歧义 | 只明确既有物体边界/接触约束，保留动作目的 |
| F4 动作缺失 | 主任务被修饰信息淹没 | 只前置来源主动作，不能删工序 |
| F5 未到终态 | 时序不足/终态无锚点 | 只明确原定终态与时点，不延长锁定时长 |
| F6 机位运动错误 | 主体运动和相机运动混写 | 只分开相机/主体句，锁定机位不改 |
| F7 跨镜不连续 | 首末状态/参考不一致 | 只替换错误相邻状态参考；先比对合同与空间图 |
| F8 时代错置 | 道具服装细节错误 | 只校正一个已证实年代细节，不改剧情物件 |
| F9 多余人物/物件 | 描述歧义或模型补全 | 只加强已有名册/物件限制，禁止删除应有角色 |
| F10 肢体/手指异常 | 遮挡/接触复杂或参考缺损 | 仅局部修复异常区域，身份与原动作不变 |
| F11 字幕/水印/乱字 | 非请求文字或源图文字误生成 | 只限制非源文字；合法字幕/对白文字不得一概去掉 |
| F12 光色漂移 | 参考/光源混杂 | 只统一一个动机光源或色彩参考，不改服装身份 |
| F13 速度异常 | 运动时间描述不符 | 只明确原时窗内节奏；不自动变速或改镜长 |
| F14 物理错误 | 接触/重力/支撑关系不明 | 只补一个已有动作的支撑/反馈约束；不得造新动作 |
| F15 视听不同步 | 时基、语音/接触锚点偏移 | 只校正已测偏移，保护对白原字和顺序 |
| F16 风格失配 | 局部借鉴覆盖主调 | 只撤销一个冲突风格参数，不重套全套预设 |
| F17 构图/裁切不当 | 目标比例/安全区错 | 只校正已批准画幅/裁切设置，不补特写 |
| F18 延展接缝 | 接续首帧/速度/色彩失配 | 只修边界参考或批准范围内接缝，不伪造无切点 |
| F19 物体持存失效 | 遮挡后身份/位置丢失 | 只明确已有物件遮挡前后状态，不凭空重生物体 |

## 修复阶梯与升级边界

L1文字澄清→L2参数校正→L3局部重绘→L4重建关键帧→L4.5有证据支持的V2V表面修复→L5设计变更提案→L6获准后期修复→L7获准删除。不是固定成本排名，也不保证低级一定便宜；按保真损失、实际服务能力、成本与授权选择。L5/L7不执行自动拆镜、删镜、改机位、改动作或改对白。没有批准则留阻断，不能为达标偷偷降规格。

## 两种计数，不能混为一谈

- 同一设计失败数：按design_id计数；同设计达到项目设定阈值时停止盲重试，复核假设或提设计变更。阈值是项目策略，不是实测成功率。
- 全镜累计预算：跨所有design_id累计所有生成/修复的次数和费用。设计变化不能清零。V2V是否计入设计失败数按事先策略，但发生的调用/费用必须计入总账；未知金额明确unknown，不当作0。

账本每行：shot_id、design_id、attempt_id、输入/输出资产与摘要、实际观察时间段、F码、症状、根因假设、唯一修改变量、保留的不变量、修复层级、调用次数/费用证据、结果、审查证据、下一步和授权。未实际运行不得填成功/失败回执。失败的审美判断和工具报错分开；一项修好不豁免其他硬门禁。生成前检查剩余预算和授权，生成后记账并重新看全镜及相邻镜。

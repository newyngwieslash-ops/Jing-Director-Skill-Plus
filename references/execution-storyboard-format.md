# 执行故事板：给人审阅与给模型生成分别交付

## 两种正式图片布局

这两种布局恢复旧版的图片交付约定。整板默认16:9（例如3840×2160），与项目影片画幅分别记录；电影本身可以是其他画幅。格数由实际关键帧决定，旧版名称中的15s/8_panel仅为兼容标识。

- `reference_15s_scene_storyboard_table`：四列 TIME、SHOT / ACTION、DIALOGUE、NOTES / VISUALS；顶部写场景、实际总时长、整板画幅；底部写实际总时长。人物参考可为紧凑侧栏或附页，不能挤压主画面。不要同时强制大底栏和“禁止大底栏”。
- `reference_15s_design_board_8_panel`：左区角色设计/三视图/服装锁，中区场景plate及俯视人物调度/机位图，右区按时间排列关键帧；底部 tone / character dynamics / cinematic approach。右区可以少于或多于8格，不能补画重复动作凑格数。

俯视调度图由已批准的地标、人物关系、轴线和机位生成；位置未知须标“示意/未定”，不编造精确坐标。代码只排版，不伪造关键帧或审批。

4.1起，中区调度依据来自本场已审阅的独立站位/走位图（`references/scene-blocking.md`），按当前镜选取所需状态；设计板内缩略图不能替代逐场两类完整图。布局或路径变化须使对应设计板和模型提示词失效并重审。

**执行路径：** 先用 `frame-jobs` 和真实图像工具产生干净帧；再使用4.2的 `render --layout design-board` 或用户明确选择的已有排版工具合成。可复用Pillow或HTML/CSS加宿主浏览器截图。使用16:9固定画布，检查文字溢出、图像裁剪和时间映射；排不下时分成带相同board_id及页码的续页，不能截断对白、删除关键帧或重复计入影片时长。缺少渲染工具时保留HTML和资产清单，明确PNG未完成。

**内置CLI范围：** `director_pipeline.py render`提供流式四列HTML和内容自适应高度的四列PNG，方便详细审阅；它没有设计板布局开关，也不保证整板16:9。因此不能把该命令的默认输出直接宣称为已完成上述16:9设计板。正式版式需要Agent按本节合成并检查。

## 版式保持、时间内容升级

保留原有TIME / SHOT-ACTION / DIALOGUE / NOTES-VISUALS四列及角色参考栏。
每镜ACTION中按entry/trigger/development/exit展示实际需要的关键帧，时间标记是**源镜内瞬间**。一页可以包含一个或多个原镜，总时长>0且≤15秒。不强制一页15秒，不强制8格，不因画面格数增加而改变影片时长。

持续时间需同时标原镜时长和当前人审页内起止。源镜原绝对时间码保留在source快照，不混淆为每张静帧的额外播放秒数。已批准EB编号与旧项目的映射应另存，`group`产生的是新分组候选，不能覆盖旧编号而不告知。

### 已批准的单镜超过15秒

不要为了人审分页把长镜改成两个剪辑镜头。保留Contract中的原shot_id、原时长、beat和不切镜设计；Agent可另写人审分页清单，每页记录 `source_shot_id`、`review_start_sec`、`review_end_sec`、`continues_same_shot: true`。例如18秒同一长镜可按动作节拍选择0–12秒与12–18秒两页，边界连续且不重复计算时长；明确“续页，无剪辑切点”。实际关键帧仍沿用源镜时间。

4.2使用 `group --pagination no-cut` 生成独立长镜审阅时间窗，再由 `render --layout design-board` 处理版面续页；旧 `group` 和默认四列 `render` 仍保持原行为。新布局参数与缺图/SVG边界见 `docs/DELIVERY_GUIDE.zh-CN.md`。`approved_recut`代表真实改镜而非分页，只有用户要求改镜时才使用，不能为绕过分组限制启用它。

## 纯净画面与角色条

`frames/`保存生成结果原图或经过明确批准的单帧编辑，禁止表头、字幕、边框、拼贴。`review/`再用代码放文字、参考条和审查标记。不要从1920宽整页板上切出低分辨率小图再放大冒充高清首帧；优先保存生图原件。

三视图/脸部/服装图放人审参考区，并按真实能力选择是否作为生图参考。角色条存在只说明供人比较；必须另有工具回执才能说“这张参考已参与本次生成”。

HTML合成器可内嵌实际PNG/JPEG/WebP；缺图显示“计划关键帧·未生成”。PNG合成器需要Pillow与本地中文字体，只支持单人审板；多板使用HTML或先输出批准的源片段。字体不随包分发。PNG仅提供核心四列表，完整参考栏保留在HTML。

## 图像验收与重试

先看轮廓位置与空间，再看人物身份和服装，最后看道具、手、眼、反射、绳线、人数与文字。每轮只修可归因问题：身份漂移更新身份约束；动作提前修时态；相机变形回到已批准机位。不要每次失败就换整套画风。

新生成仍不通过时保留失败证据并标failed。不得用生成器自己的“已符合要求”替代看图，静帧也不能证明10秒跑动、口型或摄影运动有效。

## 与旧文档差异

旧固定15秒/8格前置口径废止；旧逐格强参考和代码合成路径保留。旧整页故事板作为视频参考的默认行为废止：生成模式要挑选对应的干净帧和职责明确的参考，而不是一律上传整页。
